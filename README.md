## 🚀 Project Overview
A Java console-based enterprise blood bank management system implementing core OOP principles, GoF Design Patterns (Singleton & Strategy Patterns), and multi-role access control (Super Admin, Hospital Admin, Logistics, Patient).

---

## 🛠️ Sprint Development Roadmap
This repository is being built sequentially across 4 sprints:
- **Sprint 1 (Issues #1 to #4):** Domain Models, User Hierarchy, GoF Strategies & Input Validation
- **Sprint 2 (Issues #5 to #8):** 5-Stage Clinical Intake Pipeline, ASCII Table Engine & Core Singletons
- **Sprint 3 (Issues #9 to #12):** Interactive Role Controllers & Dashboard Menus
- **Sprint 4 (Issues #13 to #18):** Advanced Filtering, Stock Purge, Bedside Patient Onboarding & Automation Scripts
